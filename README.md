## 頁面結構

### 客戶看到的畫面（6 頁）
- `customer-01-join.html` 入會表單（30 秒、選生活主張）
- `customer-02-passport.html` 家族身份
- `customer-03-weather.html` 幸福天氣卡
- `customer-04-silent.html` 沉默模式設定
- `customer-05-bank.html` 療癒時數銀行
- `customer-06-index.html` 幸福指數自評

### 公司與店長要看到的管理頁（6 頁）

店長要看的
- `store-01-manager.html` 店長管理頁（本店會員、今日待辦、關懷名單、互動紀律）
- `staff-01-audit.html` 互動稽核表
- `staff-02-therapist.html` 專屬療癒師認證評分

公司要看的
- `hq-01-overview.html` 公司管理頁（各店比較、異常警示、鐵則稽核彙總）
- `staff-03-sister.html` 學姊遴選評分
- `staff-04-kpi.html` KPI 儀表板
